# Banking System Database

Relational banking database built in SQL Server (T-SQL).

## What's inside
- 30 tables: customers, accounts, transactions, loans, cards, branches, employees, KYC, fraud, AML and more
- Constraints: PK, FK, UNIQUE, CHECK, DEFAULT
- 65,000+ rows of synthetic data generated with T-SQL loops
- Analytical queries: top customers by balance, multiple active loans, loans per branch, fraud-flagged transactions, rapid large transactions, cross-country transactions

## How to run
Open the .sql file in SSMS and run it top to bottom.
